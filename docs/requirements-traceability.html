Requirements, implementation and evidence

Reviewed 7 November 2026. This index connects requirements to execution and acceptance; it does not approve provisional thresholds. Discovery owns product scope, software requirements owns SW-01–SW-16 and voice requirements owns V-01–V-12/A1–A11. ADR-0006 records the owner's addition of SW-16 on 7 November 2026.

Work IDs resolve in the delivery register, evidence IDs in the evidence register. Component paths identify existing source or the intended implementation boundary, not a claim of completed code. Every real-service row below remains unaccepted.
