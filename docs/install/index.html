01 / Firmware

Choose a signed package

Use the published package, or select a signed installer JSON and its matching binary files. Firmware is checked before the node is changed.

No firmware selected.

02 / Your node

Connect by USB

Use a data cable and close other serial tools. Connecting restarts the node into its USB loader and interrupts its radio connection.

No node connected.

03 / Keep a recovery copy

Save your private backup

The full flash is read twice and the copies must match. The backup contains private keys and network credentials. Save it somewhere private; it stays on this computer.

Connect a node first.

04 / Install

Confirm the exact node

Select firmware and save the connected node’s backup to review the installation.

Nothing has been written.

Then continue in the Android app

Flashing installs firmware. Group membership and everyday connection are managed in the app. The private setup-QR commissioning feature is still in development and is not performed by this installer.

After installation, disconnect and restart the node. Verify the running firmware and complete the app’s connection checks before relying on it. A USB readback alone does not establish working Wi-Fi, DHCP or group communication.
