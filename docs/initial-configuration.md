
# Connect a provisioned node

Use these steps when your node and group are already set up and you have the matching Android app. For a new board, start with [USB firmware and recovery](flash-firmware.md).

<span id="initial-configuration"></span>

## Confirm the setup

Power your assigned node and check the group and build details with the person who prepared it. If the phone is on the wrong network, use **Open Wi-Fi settings** where offered and select your assigned node’s Wi-Fi. Node Wi-Fi can work without internet. Android may switch networks, so check the active connection.

## Open the app

1. Open **Network → Groups & members** and verify the saved group.
2. Open **Manage connection**. Check the selected node and review the voice and location choices.
3. Choose **Resume connection**. Stay near the node while the app checks the connection.
4. Wait for group verification. Open **Group** to check the other member. If the app is still waiting, start with [Fix a connection](troubleshooting.md).

Resume may reconnect the group alone, rejoin voice muted, or make push to talk ready, depending on your saved choice. The app shows whether location sharing is enabled for the run. Review the choices before continuing.

## Make the first nearby check

With both phones and nodes present, send a short message in each direction. Check delivery and ask your teammate to reply. Join [voice](voice-configuration.md) muted, confirm the output and check audio both ways before separating.

## Settings to record

Record your phone model, Android version, app commit and firmware build in case you need help. Keep Wi-Fi passwords, keys and group invitations private.
