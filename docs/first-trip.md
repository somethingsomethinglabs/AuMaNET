
# Prepare for a trip

Check the actual phones and nodes you’ll take. AuMaNET has development evidence for a direct two-node link. Take independent navigation and emergency communications.

<span id="first-trip-checklist"></span>

## Before leaving coverage

- [Connect both phones](initial-configuration.md) to their assigned nodes and verify the saved group.
- Exchange a text in each direction and ask for a reply. Join voice muted and check both audio directions after choosing the output.
- [Save your map area](maps-location.md) and check the route without internet.
- Review who wants to share position, join voice or offer mobile data.
- Check each node’s power, attached antenna and protection from weather. Print-fit and weather resistance still need validation.

## During the test

If you run a [connection test](connection-tests.md), tell the group first. Managed calls and transfers can pause and calls recover muted. Keep the phone near its node when using GPS separation to interpret a link result.

## When something drops

Check phone Wi-Fi, node verification and group status in order. [Fix a connection](troubleshooting.md) lists the next step for each state.

## Record the outcome

If you’re evaluating the setup, record the exact build, phone, firmware, terrain, antenna placement and failures. Review any logs before sharing them.
